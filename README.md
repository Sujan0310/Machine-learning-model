Model Performance
The Breast Cancer dataset was evaluated using:

Decision Tree Classifier
Linear Regression (Binary Classifier)
Results
Model	Accuracy	Precision	Recall	F1-Score
Decision Tree	91.81%	93.46%	93.46%	93.46%
Linear Regression	92.98%	90.60%	99.07%	94.64%

Summary
Linear Regression achieved the highest accuracy, recall, and F1-score.
Decision Tree achieved higher precision and more balanced metrics.
For medical diagnosis, the 99.07% recall of Linear Regression is particularly valuable because it helps minimize missed positive cases.
Overall: Linear Regression performed slightly better, while Decision Tree offered more balanced precision and recall.
